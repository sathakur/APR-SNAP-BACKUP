# Operation Tab Readability Fix

Updated the portal tab interaction styling so tab labels remain readable in every state.

- Unselected hover: light background with Azure-blue text/icon.
- Selected tab: Azure-blue background with white text/icon.
- Selected badge: white badge with Azure-blue text.
- Generic button hover styling no longer overrides operation tabs.
- Keyboard focus remains visible.
- Mobile behavior remains compact.

No API, Logic App, validation, quota, backup, snapshot, or alert-suppression behavior was changed.
