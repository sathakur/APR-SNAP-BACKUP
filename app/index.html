VM snapshot requirements

4 checks
01

Managed disks

The VM OS disk and selected data disks must be Azure managed disks.

02

Snapshot scope

Select the OS disk only or the OS disk and all attached data disks.

03

VM request limit

A single snapshot request can contain a maximum of 5 unique VM hostnames.

04

User request quota

Each authenticated user can submit up to 3 snapshot requests in any rolling 24-hour period.

Important: Snapshots created while a VM is running are managed-disk snapshots and should be treated as crash-consistent. VM memory is not captured.

VM backup requirements

3 checks
01

Already protected

Only Azure VMs already protected by Azure Backup are eligible for Backup Now.

02

VM request limit

A single backup request can contain a maximum of 5 unique VM hostnames.

03

User request quota

Each authenticated user can submit up to 3 backup requests in any rolling 24-hour period.

Backup Now: This operation does not enable or change Azure Backup protection. VMs that are not already protected are reported as Not Protected. The result includes the Azure Backup status and the most recent successful recovery point.
